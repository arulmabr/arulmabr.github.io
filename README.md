# arulmabr.github.io
My personal website

## Updating the homepage

Edit `content/_index.md` for the biography on Home. The homepage displays it
below the social icons; research remains on `/research/`. The old `/about/`
and `/blog/` URLs redirect to Home.

## Updating the resume

Replace `static/files/arul-cv.pdf` with the latest PDF and push to `main`.
The website deployment publishes it at https://arulmurugan.me/files/arul-cv.pdf
and displays it on https://arulmurugan.me/resume/.
